# FMPM author instructions: check against the manuscript (read 2026-11-04)

Source: https://link.springer.com/journal/11408/submission-guidelines (read in the in-app browser; the page notes the journal "recently switched" submission systems and that the guidelines are being revised, so re-check at submission). The linked "SNAPP Double Anonymous Peer Review Guidelines" were NOT opened and must be read by the authors.

| Item | Requirement on the page | Mandatory? | Status in manuscript |
|---|---|---|---|
| Peer review | Double anonymous; author details and some statements are entered in the submission system, not in the manuscript | Mandatory | Manuscript has an empty author block; authors must enter details in the system |
| Source files | LaTeX (Springer Nature template recommended) with all style files and figures, plus compiled PDF; Word accepted | Mandatory (source) | `FMPM_Final_Manuscript/` uses sn-jnl.cls; compiled PDF must be produced by the authors (not compiled here) |
| Title page | Title, author names, affiliations, corresponding e-mail, ORCIDs if available | Mandatory | Placeholders; authors to supply in system |
| Abstract | 150 to 250 words, no undefined abbreviations or unspecified references | Mandatory | 226 words (counted); uses QLIKE, "value-at-risk" spelled out; QLIKE is named but not expanded in the abstract: authors may wish to define it |
| Keywords | 4 to 6 | Mandatory | 5 |
| JEL | "Appropriate number" of codes | Mandatory | C13, C53, C58, G11, G17 (authors to confirm) |
| Statements and Declarations | Heading with competing interests (and funding); incomplete submissions are returned | Mandatory | Heading present, content = placeholders |
| Author contributions / competing interests | Must be entered via the submission interface | Mandatory | To enter in system |
| Data availability statement | Required for original research | Mandatory | Present; repository link to insert; Yahoo data not redistributed |
| Code availability | Not stated on the page as required | Recommended | Present; link to insert |
| Headings | Decimal system, at most three levels | Mandatory | Section / subsection / unnumbered paragraph headings |
| References | Name-year in text; alphabetised by first author; only published or accepted works; DOIs as full links if available; journal abbreviations per LTWA or full title | Mandatory | Alphabetised, full journal titles, DOI links added; conference reference is a placeholder |
| Tables | Arabic numerals, cited in consecutive order, captions, footnotes with superscript letters | Mandatory | Cited in order (checked); table notes use unlettered footnotes: check |
| Figures | Arabic numerals, consecutive citation, caption in the text file, no titles/captions inside the artwork, vector preferred (EPS) or acceptable formats, lettering 8-12 pt, patterns not only colour | Mandatory/Recommended | PDF vector figures; several figures carry subplot titles and rely on colour: review |
| Footnotes | Not solely a reference; not holding bibliographic details | Mandatory | No such footnotes expected; table notes only |
| Supplementary information | PDF/csv/xlsx; cited as "Online Resource n"; each file carries title, journal, authors | Mandatory if SI is used | Supplement drafted (`FMPM_Supplementary_Material`); cited in the text as "Online Resource 1" |
| AI use | LLM use beyond copy-editing must be documented in the Methods | Mandatory | Paragraph "Reproducibility and use of AI tools" in Section 4; authors must confirm |
| Text re-use / overlap | New work that expands previous work is allowed with transparency about re-use | Mandatory (ethics) | Conference overlap disclosed in Introduction; conference reference incomplete |
| Word or page limit | None found on the page | n/a | none |
| Biography/photo | Required with the final accepted version | Later | not needed now |

Not verified: the SNAPP anonymisation guidelines; any journal-specific cover-letter requirements; article-type specific limits.
